# DIN PAY

Payment Gateway project built with React + Vite + Supabase + Vercel.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Environment

Copy `.env.example` to `.env.local` and fill in the Supabase URL and anon key.

Never put payment gateway secret keys in variables beginning with `VITE_`.
